---
name: file-bug
description: File a bug as expected versus actual, with no diagnosis. Use when something is broken and the cause is not yet established. Not for specifying work — that is write-issue — and not for recording a fix already made.
---

**Title** — the problem, six words or fewer, without the cause.

Two sections. Nothing else.

**Expected** — what should have happened.

**Actual** — what happened instead, quoted exactly, with what you ran or did to get it. Paraphrasing an error loses the string someone will search for.

Then stop. A cause you have not established is a guess, and a guess written into the issue is what everyone reads first afterwards. Ruled-out hypotheses are not findings either.

Set team, project and assignee. Add the cause when it is found; plan the fix only once it is.
